# Kadro — ИИ-персонажи и видео с ними

Отдельный сайт (Portretto не трогаем). Клиент создаёт вымышленного реалистичного персонажа и снимает с ним короткие видео. Лицо и голос сохраняются от ролика к ролику.

## Что внутри

| Файл | Что это |
|---|---|
| `server.mjs` | весь сервер одним файлом: персонажи, видео, оплата, блог, SEO |
| `index.html` | главная страница (RU/EN) |
| `app.html` | студия клиента: `/app` |
| `admin.html` | админка: `/admin` |
| `seo.html` | блог и SEO: `/seo` |
| `package.json` | команда запуска для Railway |

## Как это работает

1. **Персонаж.** Клиент задаёт имя, пол, возраст 18+, внешность, одежду и голос. Сервис рисует 4 варианта лица (nano-banana-pro), клиент выбирает одно. Дальше автоматически делается «паспорт»: ещё 3 ракурса и образец голоса (MiniMax Speech).
2. **«Говорит в кадр».** Сервис собирает кадр по паспорту и озвучивает текст голосом персонажа. Kling AI Avatar оживляет кадр с синхронизацией губ. Работает на 9 языках, включая русский.
3. **«Сцена».** Один или два персонажа в описанной сцене, с репликами и звуком. Модели: Seedance 2.0, где лицо задаётся фото, а голос — образцом, или Veo 3.1.
4. **Серии.** «Продолжить» начинает новое видео с последнего кадра предыдущего. Несколько клипов можно склеить в одно видео.

Кредиты списываются при запуске. Если генерация не удалась, они возвращаются. Для «Говорит в кадр» цена пересчитывается по реальной длине речи, лишнее возвращается. Цены и модели меняются в админке → «Пакеты и цены».

## Запуск на Railway (новый сервис)

1. Создайте на GitHub **новый** репозиторий, например `kadro`, и загрузите в корень все 7 файлов из этой папки, без подпапок.
2. Railway → **New Project → Deploy from GitHub repo** → выберите `kadro`.
3. **Volume** (обязательно, там хранятся персонажи, видео и коды): правый клик по сервису → **Attach volume** → путь `/data`.
4. **Variables** у сервиса:

| Переменная | Значение |
|---|---|
| `FAL_KEY` | новый ключ fal.ai. Старый ключ, который был в чате, лучше удалить в fal.ai |
| `ADMIN_PASSWORD` | любой надёжный пароль для `/admin` |
| `PUBLIC_URL` | адрес сайта, например `https://kadro.up.railway.app`, без `/` в конце. Нужен, чтобы fal.ai мог скачать фото и голос персонажа |
| `STRIPE_SECRET_KEY` | `sk_live_…`, тот же Stripe, что и у Portretto, или другой |
| `STRIPE_WEBHOOK_SECRET` | `whsec_…`, см. ниже |
| `STUDIO_NAME` | необязательно, название сайта (по умолчанию Kadro) |
| `CONTACT_EMAIL` | необязательно, почта в подвале сайта |

5. **Settings → Networking → Generate Domain**. Полученный адрес укажите в `PUBLIC_URL`.
6. **Вебхук Stripe:** Stripe → Developers → Webhooks → **Add endpoint**:
   - URL: `https://ВАШ-АДРЕС/api/stripe/webhook`;
   - события: `checkout.session.completed` и `checkout.session.async_payment_succeeded`;
   - скопируйте Signing secret в `STRIPE_WEBHOOK_SECRET`.
7. Проверка: откройте `https://ВАШ-АДРЕС/api/health`. Все пункты должны быть зелёными по смыслу: «Ключ принят», «подключён», «сохраняется».

## Первые шаги после запуска

- `/admin` → «Коды клиентов» → создайте себе код, например на 200 кредитов. Введите его в `/app` и снимите пару видео.
- Лучшие ролики отметьте в админке «На витрину». Они появятся на главной странице и в раскадровке в шапке.
- `/seo`: блог, ИИ-статьи, контент-план, sitemap, IndexNow, Pinterest. Всё работает так же, как в Portretto.

## Себестоимость (fal.ai, примерно)

- Персонаж: около $1.05 (4 портрета и 3 ракурса).
- «Говорит в кадр», 15 с: около $1.9 (Kling Avatar Pro) или около $1.1 (Standard).
- Сцена Seedance 2.0: около $0.30 за секунду. Veo 3.1: около $0.40 за секунду.

Цена кредита по умолчанию — около €0.17–0.25. Внизу вкладки «Пакеты и цены» админка показывает, сколько платит клиент и сколько стоит генерация.

## Правила

Только вымышленные взрослые персонажи. Описания вроде «похож на …», «знаменитость» и подобные сервис отклоняет. Возраст не ниже 18.
